The server exposes **326 HTTP endpoints** under `/api/v1`. Portal routes live under `/api/v1/client/*`, admin routes under `/api/v1/admin/*`, and the Stripe webhooks under `/api/v1/payment/*`.

## Conventions

- **Base URL** — the portal calls `/api/v1/client` on its own origin (nginx forwards `/api/v1/` and `/socket.io/` to the API). The API is also served directly at `api.nextcybr.ai` (`API_PUBLIC_URL`). The admin portal uses `VITE_API_BASE_URL`.
- **Auth** — `accessToken` (15 min) and `refreshToken` (session 7 days; portal cookie 6 h, sliding) httpOnly cookies, or `Authorization: Bearer <accessToken>`.
- **Success shape** — `{ success: true, message?, data? | <named fields> }`.
- **Error shape** — `{ success: false, message, errors?: [{ field, message }] }` from the global `errorHandler`.
- **Query objects** — `query parser` is `extended`, so `?filter[status]=ACTIVE` arrives as an object.
- **Health** — `GET /health` and `GET /api/v1/health` answer before CORS/helmet for load balancers.
