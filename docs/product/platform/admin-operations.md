# Admin operations

The NextCybr team runs the platform from a separate **admin portal**.

| Area | What the team can do | Business effect |
| --- | --- | --- |
| **Dashboard** | Platform KPIs over a chosen period: users by role, active and closed jobs, free vs paid plan split, support tickets by status | — |
| **Approvals** | Approve, reject or bulk-approve (up to 50) recruiters and mentors | Unlocks job posting / service publishing, or removes the account |
| **Users** | Browse candidates, recruiters and mentors, and open a profile with invoices and purchases | Read-only today |
| **Plans & entitlements** | Edit any plan's limits and on/off features, add plans, set per-country prices, assign a plan to a specific user | Takes effect within about a minute, no release needed |
| **Subscription discounts** | Create and edit discount codes for plan checkout | First invoice only |
| **Payments** | View subscriptions, invoices and mentorship purchases | — |
| **Mentorship activity** | See all sessions and webinar registrations. Cancel a session or registration. | Cancelling refunds the candidate |
| **Payouts** | View weekly payouts and what's in them, and re-check a stuck payout with Stripe | — |
| **Payout accounts** | See each mentor's Stripe payout status | — |
| **Support** | Ticket queue, replies, status and priority changes, delete tickets | Deleted tickets are hidden from the user too, but kept on record |
| **Blog** | Write, edit and delete posts with images | Appears on, or is removed from, the public blog |
| **Waitlist** | View and export pre-launch sign-ups | — |

:::note Not available in the admin portal yet
Creating, editing or deleting users, job/applicant/hire reports, and the Reports and Settings screens. See [Known limitations](../known-limitations.md).
:::
