# Blog & launch mode

## Blog

- Written by the NextCybr team in the admin portal, with rich text and images.
- Public: anyone can read `/blogs` without an account.

## Coming-soon mode

Before launch, or on chosen domains, the portal can show a **coming-soon page** instead of the app.

| Visitor action | Result |
| --- | --- |
| Joins the waitlist | Email saved once (duplicates ignored) and a welcome email sent. The team can export the list. |
| Enters the access password | Gets into the full portal (for testers and partners) |

Coming-soon mode is switched on per environment and domain by configuration, without code changes.
