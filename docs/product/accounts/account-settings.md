# Profiles, privacy & settings

## Who can see a profile

| Viewer | What they see |
| --- | --- |
| Anyone with the link (public profile page) | Only profiles set to **Public**. Private profiles show as not found. Mentor profiles include ratings and reviews. |
| Recruiters | Full candidate profiles, for sourcing |
| Mentors | Full candidate profiles, within a monthly allowance (Free 25 / Pro 250 views) |
| Candidates | Company pages (with open jobs) and mentor pages (with services) |

- **Visibility** (Public / Private) is a setting on every role's profile. The default is **Public**.
- **Anonymous mode**: a candidate can hide their identity where they appear to others.

## Settings

| Area | Behaviour |
| --- | --- |
| Contact details | Phone needs a country code. The alternate email can't be the same as the main email. |
| Profile visibility | Public / Private |
| Notification preferences | Toggle application updates, job alerts, activity, promotions and newsletter. **Security emails can't be turned off.** Everything is on by default. |
| Security | Change password, see signed-in devices, sign out one or all devices |
| Deactivate account | Self-service. Signs the user out everywhere immediately and sends a confirmation email. They can't sign in again until support reactivates them. |

## Edge cases worth testing

- Set a profile to Private, then open its public link while signed out: not found.
- Turn off "Application updates" and have a recruiter change an application status. No email should arrive, but the in-app notification still appears.
- Try to turn off security emails: not possible.
- Deactivate, then try to sign in: refused with a "contact support" message.
