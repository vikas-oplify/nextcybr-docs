# Candidate sourcing

## Ways to find candidates

| Tool | What it does | Free | Pro / Enterprise |
| --- | --- | :-: | :-: |
| **Standard search** | Filter by location, contract type, experience, skills and name | Unlimited | Unlimited |
| **Suggested candidates** | Rule-based suggestions | Unlimited | Unlimited |
| **AI candidate search** | Describe who you need in plain words, and AI ranks candidates | 5 / month | Unlimited |
| **AI match run** | "Find candidates for this job": AI scores candidates against a specific posting | 2 / day, 25 candidates scored | Unlimited, 50 (Pro) / all (Enterprise) scored |
| **Match explanations** | Why each candidate matches | Basic | Detailed |

**Re-opening a job's last match run is free.** It shows the saved results without using a run. Only asking for a fresh run counts. When the daily runs are used up, the message says they renew tomorrow and that saved results are still available.

## Organising candidates

| Tool | Rule |
| --- | --- |
| **Shortlist** | Free: up to **12** shortlisted at once **and** at most **6 new additions per calendar month**. Removing someone frees a place but doesn't give back the monthly addition. Pro/Enterprise: unlimited. |
| **Notes** | Private notes on a candidate, optionally tied to one application. Visible only to that recruiter. |
| **Saved searches** | Pro/Enterprise: save a search or match run and reopen it later **without using any AI allowance** |
| **Export** | Pro/Enterprise: download the shortlist as CSV |

## Reaching out

- Recruiters start conversations with candidates. **Candidates can't message a recruiter first**, only reply.
- Free recruiters can start **5 new conversations per day**. Replying in an existing conversation doesn't count.

## Edge cases worth testing

- Run a match on a job, reload the page → the same results, and the run counter doesn't change. Ask for a re-run → it counts.
- Free: use 2 match runs, then try a third → blocked with the "renews tomorrow" message. Saved results still open.
- Free: add 6 to the shortlist, remove 1, add another → blocked (monthly additions used) even though there's room.
- Free recruiter: start 5 new chats, then a 6th the same day → blocked. Replying to an existing chat → allowed.
- Free recruiter tries to export → upgrade prompt.
